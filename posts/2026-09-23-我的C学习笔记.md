##六.运算符
**说明特定操作的符号**

分类：算术运算符，赋值运算符，关系运算符，逻辑运算符和位运算符等

按修饰的操作数个数分类：单目，双目和三目运算符

1.算术运算符

+，-，*（乘），/（除），%（模），++（自增），--（自减）

%也是除法，但最后结果取值为余数

/整数除法，如果两边都是整数，结果为整数，不保留小数。如果两边有一个是浮点数结果保留小数。eg：5 / 2.0=2.500000

++和--（单目）：

  前置：先自增自减后运算

  后置：先运算后自增自减

  eg：
    前置自增：
     
     int a = 5;
    int b = ++a; 
    // 步骤：a 先加 1 变成 6，然后把 6 赋值给 b
    // 结果：a = 6, b = 6
    
后置自增：

    int a = 5;
    int b = a++; 
    // 步骤：先把 a 原来的值 5 赋值给 b，然后 a 自己再加 1 变成 6
    // 结果：a = 6, b = 5

2.关系运算符

>,<,>=（大于等于）,<=（小于等于）,==（等于）,!=（不等于） (1为真，0为假）

eg：
   
    #include <stdio.h>
   
    int main() {
    int a = 10;
    int b = 20;

    // 1. 大于
    printf("a > b 的结果是: %d\n", a > b);   // 10 > 20 是假，输出 0

    // 2. 小于
    printf("a < b 的结果是: %d\n", a < b);   // 10 < 20 是真，输出 1

    // 3. 大于等于
    printf("a >= 10 的结果是: %d\n", a >= 10); // 10 >= 10 是真，输出 1

    // 4. 小于等于
    printf("b <= 15 的结果是: %d\n", b <= 15); // 20 <= 15 是假，输出 0

    // 5. 等于（注意是双等号 ==）
    printf("a == b 的结果是: %d\n", a == b);  // 10 == 20 是假，输出 0

    // 6. 不等于
    printf("a != b 的结果是: %d\n", a != b);  // 10 != 20 是真，输出 1

    return 0;
    }
 
运行结果为：

    a > b 的结果是: 0
    a < b 的结果是: 1
    a >= 10 的结果是: 1
    b <= 15 的结果是: 0
    a == b 的结果是: 0
    a != b 的结果是: 1
    
3.逻辑运算符

&&(并且）
  
  逻辑与：左右两边都为真结果为真，左右两边有一个为假，结果为假

||（或者）

  逻辑或：左右两边有一个为真，结果为真，左右两边都为假，结果为假。

！（单目）非

  逻辑非：修饰的为真，结果为假，修饰的为假，结果为真

eg：

    #include <stdio.h>

    int main() {
    int age = 20;          // 年龄
    int isDrunk = 0;       // 0 表示没喝醉，1 表示喝醉了

    // 1. 逻辑与 && （两个条件必须同时满足）
    // 只有 age >= 18 并且 isDrunk == 0 同时成立，才能开车
    if (age >= 18 && isDrunk == 0) {
        printf("条件1：可以开车\n"); 
    } else {
        printf("条件1：不能开车\n");
    }

    // 2. 逻辑或 || （只要满足一个条件就行）
    // 只要 age 满18 或者 isDrunk 为0（没喝醉），就满足其中一个
    if (age >= 18 || isDrunk == 0) {
        printf("条件2：满足至少一个条件\n");
    }

    // 3. 逻辑非 ! （唱反调）
    // 如果 !isDrunk 为真，说明 isDrunk 是 0（没喝醉）
    if (!isDrunk) {
        printf("条件3：检测到没有喝醉\n");
    }

    return 0;
    }
  
运行结果：

    条件1：可以开车
    条件2：满足至少一个条件
    条件3：检测到没有喝醉

3.位运算符

&：位与：操作的两个位都是1，得到的结果为1，其他结果为0

  • 经典用途：清零、取特定位（掩码）。
  • 例子：
  
    5 & 3
	• 5 的二进制：0101
	• 3 的二进制：0011
	• 按位与结果：0001 （十进制 1）

|：位或：操作的两个数都是0，得到的结果就是0，其他情况都是1

  • 经典用途：把某些位置为 1。
  
  • 例子：
    
    5 | 3
	• 5 的二进制：0101
	• 3 的二进制：0011
	• 按位或结果：0111 （十进制 7）

~（单目）：位非：位的值为1，结果变成0，位的值为0，结果变成1

  例子：
  
    5 ^ 3
	• 5 的二进制：0101
	• 3 的二进制：0011
	• 异或结果：0110 （十进制 6）

^：位异或：操作的两个位不同就是1，其他结果为0

  • 例子：
  
    ~5
	• 5 的二进制（假设8位）：00000101
	• 取反结果：11111010 （这是补码，十进制是 -6）

<<（整体向左移动，右边补 0）

  • 效果：相当于乘以 2^n。

  • 例子：

    5 << 1
    • 5 的二进制：00000101
	• 左移 1 位：00001010 （十进制 10，刚好是 5 × 2）
	• 左移 2 位：00010100 （十进制 20，刚好是 5 × 4）

>>（整体向右移动，左边补 0 或符号位）

  • 效果：相当于除以 2^n（取整数商）。

  • 例子：
  
    10 >> 1
    • 10 的二进制：00001010
	• 右移 1 位：00000101 （十进制 5，刚好是 10 ÷ 2）

5.其他运算符

1. sizeof 运算符（求字节数）
 
  • 作用：计算一个数据类型或变量在内存中占用的字节数。
  
  • 特点：它是个单目运算符，不是函数。返回值类型是 size_t（无符号整数），所以打印时最好用 %zu。
 
  • 例子：

    printf("%zu\n", sizeof(int));   // 输出 4 (32位系统)
    printf("%zu\n", sizeof(char));  // 输出 1
    int a = 10;
    printf("%zu\n", sizeof(a));     // 输出 4

2. ?: 三目运算符（唯一的三元运算符）
 
  
  • 语法：条件 ? 表达式1 : 表达式2

  • 逻辑：如果“条件”为真，整个式子返回“表达式1”的值；否则返回“表达式2”的值。

    int a = 10, b = 20;
    // 找出两个数中的最大值
    int max = (a > b) ? a : b; 
    printf("最大值是: %d\n", max); // 输出 20

3. , 逗号运算符（顺序求值）
 
逗号在 C 语言里不仅可以分隔变量，还可以当运算符。

   • 作用：把多个表达式连接起来，从左到右依次计算，最终整个式子的结果等于最右边那个表达式的值。

    int a = 1, b = 2, c;
    // 先算 a+1，再算 b+2，最后把 b+2 的结果赋给 c
    c = (a + 1, b + 2); 
    printf("c = %d\n", c); // 输出 4 (因为 b=2, 2+2=4)

🔴运算符是有优先级的
    




## 一.C程序的主要包括

###1.a.预处理器指令：#include<stdio.h> 在程序的第一行，告诉C编译器在实际编译之前要包含stdio.h头文件

系统头文件使用尖括号<> 自定义头文件使用双引号“”  头文件定义了函数，宏，常量等是程序能够使用预定义的库函数
eg:#include<stdio.h>(系统头文件） #include“myheader.h"(自定义头文件）

b.宏：形式一般在程序第二行 eg:#define PI 3.14  在预处理阶段时所有的PI都变成3.14

宏的两种类型 1.对象宏（常量宏）就是给值起了一个外号 2.函数宏（带参数的宏） 它能像函数一样接收参数，但绝不是函数 eg：#define SQUARE(×） × * × 当你写SQUARE（5）时，它会替换成5 * 5

常见陷阱：写成1+2这种时要加括号 不加括号就变成1+2*1+2变成1+2+2 正确写法：#define SQUARE（×）（（×）* (×））

注：stdio是standard input output .header （标准输入输出头文件） C的功能都在标准库里，所以要在第一行写预处理器指令

###函数

在C语言中，函数由一个函数头和一个函数主体组成

a.函数声明:告诉编译器函数的名称，返回类型和参数，他让编译器在遇到函数调用时，知道该如何处理，而不必立刻知道函数的具体实现。

    int add(int a, int b) {
    int sum = a + b;
    return sum; 
    }

返回值（int）：我准备给你端出一个整数
· 函数名（add）
· 参数（int a, int b）
· 大括号里的（函数体）：我先把 a 和 b 加起来变成 sum，然后 return sum（把算好的 sum 端出去给你）

（1）只有函数头，末尾必须加分号；C语言是自上而下编译的。编译器在遇到函数调用时，必须提前知道函数的返回类型、参数类型和个数，才能分配正确的内存并生成指令。声明就是为了给编译器吃“定心丸”。
eg`int add(int a, int b);`，可以声明无数次。

    int add(int a, int b) {    // <--- 这部分就是【函数头】
      int sum = a + b;       // <--- 这部分就是【函数体】
      return sum;            // <--- 这部分也是【函数体】
      }                          // <--- 大括号结束

函数头：int add(int a, int b)。它包含了三个核心信息：返回类型（int）、函数名（add）、参数列表（int a, int b）。
函数体：大括号 { } 以及里面的所有代码。它是函数真正执行动作的地方。

b.函数定义：函数头加函数体

###3.变量

变量时程序可操作的储存区的名称

a.条件：变量的名称可以由字母，数字和下划线字符组成 ❤️它必须以字母或下划线开头 大写字母和小写字母是不同的

b.类型：char:通常是一个字节（八位），这是一个整数类型（存放“单个符号”） eg：char letter = 'A' A在ASCII码表中对应的数字是65 想打印成字符（字母）：用%c。想打印成数字（ASCII码）：用%d

   char letter = 'A';
   
   printf("字符是：%c\n", letter); // 输出：A

   printf("对应的数字是：%d\n", letter); // 输出：65

int：整型，4个字节，取值范围-2147483648到2147483647 eg：int age = 18 打印用%d

  int a = 10;
  
  printf("数字是：%d\n", a); // 输出：数字是：10
  
float：单精度浮点值（小数）。大概能保留小数点后6到7位的有效数字(%f)

double：双精度浮点值。能保留小数点后大概15到16位有效数字(%f)

void：表示类型的缺失

c.变量定义：告诉编译器在何处创建变量的存储，以及如何创建变量的存储

变量定义指定一个数据类型，并包含了该类型的一个或多个变量的列表

格式：type variable_list;

eg:int age; (age被定义为一个整型变量

d.变量初始化

格式：type variable_name = value;(值）

eg：int x = 10

后续初始化变量：eg：

          int x；
          x = 20；

**   以下是不同类型的变量在没有显式初始化时的默认值：

整型变量（int、short、long等）：默认值为0。

浮点型变量（float、double等）：默认值为0.0。

字符型变量（char）：默认值为'\0'，即空字符。

指针变量：默认值为NULL，表示指针不指向任何有效的内存地址。

数组、结构体、联合等复合类型的变量：它们的元素或成员将按照相应的规则进行默认初始化，这可能包括对元素递归应用默认规则。**

🔴总结起来，C 语言中变量的默认值取决于其类型和作用域。全局变量和静态变量的默认值为 0，字符型变量的默认值为 \0，指针变量的默认值为 NULL，而局部变量没有默认值，其初始值是未定义的。

e.变量的声明

变量的声明有两种情况：

1、一种是需要建立存储空间的。例如：int a 在声明的时候就已经建立了存储空间。

2、另一种是不需要建立存储空间的，通过使用extern关键字声明变量名而不定义它。 例如：extern int a 其中变量 a 可以在别的文件中定义的。

（除非有 extern 关键字，否则都是变量的定义）

  extern int i; //声明，不是定义
  
  int i; //声明，也是定义

  eg:
  
    #include <stdio.h>
 
    // 函数外定义变量 x 和 y
    int x;
    int y;
    int addtwonum()
    {
    // 函数内声明变量 x 和 y 为外部变量
    extern int x;
    extern int y;
    // 给外部变量（全局变量）x 和 y 赋值
    x = 1;
    y = 2;
    return x+y;
    }
    int main()
    {
    int result;
    // 调用函数 addtwonum
    result = addtwonum();
    printf("result 为: %d",result);
    return 0;
    }



  
3. 语法细节与踩
- 声明里的参数名可以省略：`int add(int, int);` 也是合法的。
- 声明末尾的分号绝对不能少，否则会引发诡异的语法错误。
- 如果函数不接受任何参数，现代C语言规范要求写上 `void`：`int func(void);`，而不是留空 `int func();`。

在大型项目中，函数声明通常放在 `.h`（头文件）里，函数定义放在 `.c`（源文件）里。主程序通过 `#include "xxx.h"` 引入声明，从而实现模块化编程。
主函数：每个C程序有且只有一个main（）函数，是程序的执行入口 程序从main()开始执行，返回值通常为0表示程序成功执行，非零值表示出现了错误
