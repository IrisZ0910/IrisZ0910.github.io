## 一.文件管理类

**cd - 切换目录**

详细解释：改变当前工作目录，是导航linux文件系统的核心命令

常用参数：

 1. cd /根目录(最开始的页面)

  ls 可以列出当前目录下的文件夹以及有哪些文件（子目录）

  pwd可以看见当前所在位置的路径

   eg: cd /etc +回车，就进入了etc这个文件夹

 从根目录想进入etc的子目录里的其中一个时有两种方式

   (1)直接cd /etc/目录
 
   (2)用相对目录 先打cd /etc  然后输入pwd  然后直接打cd 目录就可以了 （这个叫相对目录）

 2. ~:当前用户的主目录（cd ~等价于直接输入cd）

   cd ~ 进入用户的家目录(个人专属文件夹)（在家目录里相对安全，练习时可以在家目录里练）

 3. ..:上一级目录

 cd .. 进入上一级目录

 4. -：上一次所在目录

🔴进入带空格的文件夹时，要加引号

 **ls - 列出目录内容**

 详细解释：列出指定目录下的文件和子目录，是Linux中最基础，使用频率最高的命令

 常用参数：

1. ls -l:以长格式显示，包含权限，所有者，大小，修改时间等详细信息

  d开头就是文件夹，-开头就是文件

2. ls -lh:在当前的格式基础之上,可以看见文件的大小 

3. ls -alh:所有文件，可以看隐藏文件  也可以ls -a直接看隐藏文件，不带格式

🔴使用pwd看当前位置，然后用ls 可以看到网站的访问记录

**mkdir - 创建目录**

  使用mkdir 名字，就可以创建一个新目录（当创建多个文件时，要注意只能创建多个同一级的目录）

  但如果想按照层级来创建，要用-p

  eg：

   mkdir -p test1/test2/test3 (注：-p前后要加空格)

   1.-p：递归创建多级目录（如果父目录不存在，会自动创建）

   2.-m：创建目录时直接设置权限（如 mkdir -m 755 test）

**rm - 删除文件或目录**

  详细解释：删除指定的文件或目录，是Linux中最危险的命令之一

 常用参数：

   1.-r:递归删除目录及其所有内容

   2.-f:强制删除，不提示确认

   3.-i:交互式删除，删除前会提示确认

🔴🔴🔴1.绝对不要执行rm -rf / 或 sudo rm -rf /,这会删除整个系统

  2.不要在错误的目录执行rm -rf*,这会删除当前目录下的所有内容

  3.删除符号链接只会删除链接本身，不会删除目标文件
