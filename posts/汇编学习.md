# 给自己一句话：学汇编不是背指令，而是学会看执行这条指令前后状态怎么变

## 一.基础模型

**“基础模型” = 初学汇编时的最小心智地图：CPU有哪些状态，指令怎么改这些状态（就是CPU + 内存 + 他们之间的数据流）**
 
 1.CPU是一个“状态机”它反复做三件事：取指令，译码，执行   每条指令只做一件事情：改变“寄存器，内存，标志位，rip”中的某些状态。

 2.汇编程序里的五类状态 = 通用寄存器 + rip + rsp + 标志位 + 内存

 （1）通用寄存器：CPU内部的小存储，速度最快

 （2）指令指针：下一条要执行的指令地址

 （3）栈指针：当前栈顶地址

 （4）标志位：上一条运算的结果属性

 （5）内存：一个大字节数组，按地址访问

 💕汇编指令基本就是在这些状态之间搬数据，做运算，改控制流。

 3.数据表示：十六进制，字节，小端

  （1）1字节 = 8位  
  
  （2）十六进制一位 = 4位，所以2个十六进制位 = 1字节
  
  （3）x86-64时小端序：低字节放在低地址里

  🔴🔴🔴看内存时，地址从低到高；读多字节值时，要反过来拼

4.寄存器：先记“8个常用+2个特殊”

 x86-64有16个通用寄存器：rax rbx rcx rdx rsi rdi rbp rsp r8 r9 r10 r11 r12 r13 r14 r15

 (1)rax:返回值，系统调用号，累加

 （2）rdi：第一个函数参数

 （3）rsi：第二个函数参数

 （4）rdx：第三个函数参数

 （5）rcx：第四个函数参数

 （6）r8：第五个函数参数

 （7）r9：第六个函数参数

 （8）rsp：栈顶指针

 （9）rbp：栈帧基址，常用来定位局部变量

 （10）rip：下一条指令地址，不能直接mov改

 寄存器有不同位宽名字：

    64位：rax
    32位：eax
    16位：ax
    8位：al

 🔴写32位寄存器会清零高32位（意思就是eax不是独立寄存器，它是rax的低32位。你写eax时，CPU会把rax的低32位改成新值，同时把高32位强制清零）

4.内存寻址

 最常用形式：

     [基址 + 索引*比例 + 偏移]

  eg：

     mov eax,[rbx]        ;取rbx指向的4字节
     mov eax,[rbx+8]      ;取rbx+8处的4字节
     mov eax,[rbx+rcx*4]  ;数组访问：基址+索引

5.第一批指令：只记它们改变什么

  （1）mov：搬数据

    mov eax, 3       ; eax = 3
    mov rdi, rax     ; rdi = rax
    mov [rsp], rax   ; 把 rax 写到栈顶内存

 （2）add/sub：加减，并改标志位

    mov eax, 5
    add eax, 3       ; eax = 8
    sub eax, 1       ; eax = 7

（3）cmp：做减法，但不保存结果，只改标志位

    cmp eax，7

它相当于eax - 7，但eax不变，只设置：

   ZF=1：相等

   SF：结果为负

   CF：无符号借位

   OF：有符号溢出

（4） jmp/jcc：改rip

    jmp label        ; 无条件跳
    je  label        ; ZF=1 时跳，相等
    jne label        ; ZF=0 时跳，不相等
    jg  label        ; 有符号大于
    jl  label        ; 有符号小于
    ja  label        ; 无符号大于
    jb  label        ; 无符号小于

  核心组合：

    cmp eax, 7
    je equal

 意思是：比较eax和7，如果相等就跳到equal

（5）push/pop/call/ret

 先记行为：

    push rax   ; rsp = rsp - 8; [rsp] = rax
    pop rax    ; rax = [rsp]; rsp = rsp + 8
    call f     ; 把返回地址压栈，然后跳到 f
    ret        ; 从栈弹出返回地址到 rip

 栈是低地址增长的。   


## 二.基础

### 1.注释
 
  注释以分号（;）开头。

  注释可以放在程序中的任何位置，;之后的所有内容都会被汇编器忽略。

### 2.常量

 在 NASM 中，可以用equ定义字符汇编期常量。 例如，下面定义了一个名为UNIVERSE、值为42的常量：

    UNIVERSE equ 42

常量在定义时求值一次，之后_不能_重新定义。

### 3.通用寄存器（GPRs）

  在汇编中，我们通常用寄存器来存储值，而不是变量。 CPU 寄存器是处理器内部的一小块高速内存。 大多数计算都在 CPU 的寄存器中进行。

  有些寄存器用于各种不同的计算，称为通用寄存器（GPRs）。 另一些则有特殊或专门的用途。

  在 x86-64 中，有 16 个 64 位通用寄存器（GPRs），它们也可以按 32 位、16 位或 8 位访问。 下面列出了这些通用寄存器，其中rn里的n取值为 8 到 15：r8、r9、r10、r11、r12、r13、r14和r15。

    64-bit    32-bit    16-bit    8-bit
    rax       eax        ax    ah/al
    rbx       ebx        bx    bh/bl
    rcx       ecx        cx    ch/cl
    rdx       edx        dx    dh/dl
    rsi       esi        si    sil
    rdi       edi        di    dil
    rbp       ebp        bp    bpl
    rsp       esp        sp    spl
    rn        rnd        rnw    rnb

  当使用不足 64 位时，访问的通常是寄存器的低位部分。 这条规则的例外是ah、bh、ch和dh，它们访问的是寄存器 16 位部分中的高 8 位。
