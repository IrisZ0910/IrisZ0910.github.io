一.linux目录结构#

1.第一梯队：（1）/root：是超级管理员专属的“私人房间”（主目录）

（2）/home：普通用户，家目录的仓库，通常放个人数据（eg：日常文件夹，个人代码和文件，个人配置文件（隐藏文件））

（3）🔴/etc：系统所有配置文件目录（eg：系统服务，配置参数，账号，开机自启）后期改ip或主机名等要用到

（4）/bin + /sbin：（所有用户都能执行的一个基础命令，sbin是管理员才能用的命令）

（5）/usr：作用是系统安装软件，应用程序，文档库文件的存放地（头文件库文件都是存放在这）

（6）/var：动态变化数据目录（日志，缓存，排查故障就需要去看）

2.第二梯队：（1）/dev：设备文件目录（硬件都在这里面）

二.文件管理类#

cd - 切换目录

详细解释：改变当前工作目录，是导航linux文件系统的核心命令

常用参数：

  1. cd /根目录(最开始的页面)

ls 可以列出当前目录下的文件夹以及有哪些文件（子目录）

pwd可以看见当前所在位置的路径

eg: cd /etc +回车，就进入了etc这个文件夹

从根目录想进入etc的子目录里的其中一个时有两种方式

(1)直接cd /etc/目录

(2)用相对目录 先打cd /etc 然后输入pwd 然后直接打cd 目录就可以了 （这个叫相对目录）

  1. ~:当前用户的主目录（cd ~等价于直接输入cd）

cd ~ 进入用户的家目录(个人专属文件夹)（在家目录里相对安全，练习时可以在家目录里练）

  1. ..:上一级目录

cd .. 进入上一级目录

  1. -：上一次所在目录

🔴进入带空格的文件夹时，要加引号

ls - 列出目录内容

详细解释：列出指定目录下的文件和子目录，是Linux中最基础，使用频率最高的命令

常用参数：

  1. ls -l:以长格式显示，包含权限，所有者，大小，修改时间等详细信息

d开头就是文件夹，-开头就是文件

  1. ls -lh:在当前的格式基础之上,可以看见文件的大小

  2. ls -alh:所有文件，可以看隐藏文件 也可以ls -a直接看隐藏文件，不带格式

🔴使用pwd看当前位置，然后用ls 可以看到网站的访问记录

mkdir - 创建目录

使用mkdir 名字，就可以创建一个新目录（当创建多个文件时，要注意只能创建多个同一级的目录）

但如果想按照层级来创建，要用-p

eg：

mkdir -p test1/test2/test3 (注：-p前后要加空格)

1.-p：递归创建多级目录（如果父目录不存在，会自动创建）

2.-m：创建目录时直接设置权限（如 mkdir -m 755 test）

rm - 删除文件或目录

详细解释：删除指定的文件或目录，是Linux中最危险的命令之一

常用参数：

1.-r:递归删除目录及其所有内容

2.-f:强制删除，不提示确认

3.-i:交互式删除，删除前会提示确认

🔴🔴🔴1.绝对不要执行rm -rf / 或 sudo rm -rf /,这会删除整个系统

2.不要在错误的目录执行rm -rf /*,这会删除当前目录下的所有内容

3.删除符号链接只会删除链接本身，不会删除目标文件

cp - 复制文件或目录

详细解释：将文件或目录从一个位置复制到另一个位置

可以利用cp备份文件

常用参数：

  1. -r：递归复制目录及其所有内容

  2. -a:归档模式，保留文件的所有属性（权限，时间戳，所有者等）

最常用：用cp把文件备份。eg：cp 文件 文件.bak （cp 原始文件 新文件）

🔴当你想要原模原样的文件，且有权限访问内容时用-a

当用-r时，可以将一个目录复制到另一个目录里 eg：cp -ar /etc/peizhi/ (这样就直接把etc目录以及整个内容都复制在peizhi里了)

❤️常见错误：（1）忘记加-r参数复制目录，会提示“omitting directory”错误

（2）复制到已存在的文件会直接覆盖，不会提示

（3）复制符号链接会复制链接本身，而不是目标文件（使用cp -L可以复制目标文件）

mv - 移动或重命名文件/目录

详细解释：移动文件或目录到另一个位置，或者重命名文件/目录

常用参数：

1.-i：交互式移动，覆盖前会提示确认

2.-f：强制移动，不提示确认

3.-n：不覆盖已存在的文件

用法：mv 文件 /目录 （将文件移动在这个目录里）

mv 文件名 新文件名（相当于改名）

find - 搜索文件和目录

详细解释：在指定的目录树中搜索符合条件的文件和目录，功能非常强大

常用参数：

1.-name：按文件名搜索（支持通配符）

2.-size：按文件大小搜索（+100M表示大于100MB，-10K表示小于10KB）

3.-mtime：按修改时间搜索（-7表示7天内修改的，+就是代表几天之外的，-就是代表几天之内的）

❤️常见错误：路径错误导致搜索范围不对（eg：find/-name"*.txt"会搜索整个系统，速度很慢）

~find / -name 文件名 （直接在全盘找文件） eg：find /目录 -name（就是在这个目录下找文件）

通配符：.*,当只记得名字不记得后缀时，就可以用通配符占用寻找（模糊搜索的方法）

~find / -size +100M (就可以找到大于100MB的文件)

~find / -mtime （通常适用于老文件，进行转移或者直接删除）

三.文件查看类#

cat - 查看文件内容

详细解释：链接并打印文件内容到标准输出

常用参数：

1.-n: 显示所有行的行号 （eg：1.……2.……）使用行号可以快速定位重要信息

2.-A；显示特殊字符

3.-b：只显示非空行的行号

4.-s：压缩连续的空行为一行

❤️常见错误：（1）用cat查看大文件（如GB级别的日志），会导致终端卡顿甚至崩溃

（2）cat > file.txt会直接覆盖文件内容，而不是追加（追加应该用cat>>file.txt）

cat /文件（就可以查看内容）

使用-A时，eg：用tab和用空格肉眼看都是一样的，用-A就可以查看到区别（^I是tab,$是回车键）

tail - 查看文件尾部内容

详细解释：输出文件的最后几行内容，特别适合查看日志文件 （日志：软件的工作过程的记录）

常用参数：

-n N：显示最后N行内容（N是自己取值，eg：1就是查看最后一行的新内容）

-f：实时跟踪文件的新增内容（按Ctrl+C停止）

❤️常见错误：（1）tail -f会一直运行，直到被手动终止

（2）文件被删除后，tail -f会停止跟踪（可以用tail -F继续跟踪新创建的同名文件）

vim - 文本编辑器

详细解释：Linux系统自带的高级文本编辑器，用于编辑，修改，查看系统配置文件，普通文本文件，支持多种编辑模式，是运维核心编辑工具

常用参数/操作：

1.vim文件名：打开或新建文件，进入普通模式

2.i：进入插入编辑模式，可输入内容

3.esc：退出编辑模式，返回普通模式

4.:w:保存文件修改

5.:q:正常退出文件

6.:wq / :x:保存并退出

7.:q!:强制退出，不保存任何修改

vim 文件名：可以打开这个文件

最基本用法：当日志用（:wq是保存并退出）

❤️常见错误：(1)直接关闭终端强制退出，产生swp交换文件，导致文件锁定无法编辑

（2）混淆编辑模式和命令模式，无法输入内容或无法保存退出

（3）修改系统配置文件后不备份，出错后无法回滚恢复

（4）直接用:q!强制退出，误丢弃已修改的有效内容

grep - 文本搜索

详细解释：在文本中搜索包含指定模式的行，是linux中最强大的文本处理工具之一

常用参数：

1.-i:忽略大小写

2.-n：显示匹配行的行号

3.-v:反向匹配，显示不包含指定模式的行

可以用grep找出重点来看ip

eg：grep ip 文件名（筛选跟它的相关信息）
