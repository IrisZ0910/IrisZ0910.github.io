## 十三.输入函数

Python 的输入函数主要是 input()，读取键盘输入。 
 
1. 基本用法

       name = input("请输入姓名：")
       print("你好，", name)
 
运行：
      
       请输入姓名：小明
       你好， 小明
 
🔴关键点：input() 的返回值永远是字符串 str

2. 输入数字要转换
   
       age = int(input("请输入年龄："))
       print(age + 1)
 
输入：

     请输入年龄：18
     19
 
浮点数：
     
     score = float(input("请输入成绩："))
     print(score * 2)
 
输入：

    请输入成绩：85.5
    171.0

3. 一次输入多个值
 
用 split() 按空格切分：

    a, b = input("请输入两个数，用空格分隔：").split()
    a = int(a)
    b = int(b)
    print(a + b)
 
输入：

    请输入两个数，用空格分隔：3 5
    8
 
更简洁的写法：

    a, b = map(int, input("请输入两个数：").split())
    print(a + b)    

简单理解：

1. input() 返回字符串，数字要 int() / float() 转换。

2. input("提示语") 的提示语会显示在输入前。

3. 多个值用 split() 切分，配合 map() 转换类型。

4. 输入不是数字时 int() 会抛 ValueError，可用 try/except 处理。

split（）：作用时按指定分隔符，把一个字符串切成多个字串，返回一个列表 

语法：字符串.split（分隔符）  如果不写分隔符，默认按任意空白字符切分（空格，换行，Tab等）

map（）：把一个函数依次作用到可迭代对象的每个元素上，返回一个新的迭代器

语法：eg：map（int，nums） 相当于把nums中的元素都转换为整数

map对象是一次性的，print取完就空了

!= 不等于 3 != 4 True

4.三目运算符
 
 （条件表达式）是一行写 if-else 的简写，用来根据条件二选一。
 
语法：值1 if 条件 else 值2
 
含义：条件为 True，取值1；条件为 False，取值2。

eg：

    age = 20
    result = "成年" if age >= 18 else "未成年"
    print(result)      # 成年

## 十七.循环
 
1. for 循环
 
遍历一个序列（列表、字符串、range 等），逐个取出元素。
 
语法：
for 变量 in 可迭代对象:
    循环体       

eg：

    for i in range(5):
    print(i)
 
 输出：
  
    0
    1
    2
    3
    4

3. while 循环
 
**条件为真就一直循环。**
 
语法：
 while 条件:
    循环体

eg：

    i = 0
    while i < 5:
    print(i)
    i += 1        # 千万别忘了，否则死循环
 
输出：

    0
    1
    2
    3
    4

场景 用哪个
知道循环次数 / 遍历序列 for
不知道次数，靠条件结束 while

5.循环嵌套
 
一个循环里面再放一个循环，外层走一次，内层走一整圈。
 
1. 基本结构

       for i in range(3):        # 外层
        for j in range(2):    # 内层
          print(i, j)
 
输出：

    0 0
    0 1
    1 0
    1 1
    2 0
    2 1
 
规律：
外层 i=0 → 内层 j 走完 0,1
外层 i=1 → 内层 j 走完 0,1
外层 i=2 → 内层 j 走完 0,1
