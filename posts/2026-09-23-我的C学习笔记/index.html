C语言的笔记#

一.关键字#

保留字：已被C语言本身使用，不能做其他用途的字

常见的32种：

auto,break,case,char,const,continue,defauit,do

double,else,enum,extern,float,for,goto,if

int,long,register,return,short,signed,sizeof,static

struct,switch,typedef,union,unsigned,void,volatile,while

二.标识符（给变量，函数，数组，结构体等起的名字）#

用来标识某个实体的符号

命名及规范：

1.只能由字母，数字和下划线组成，且以字母和下划线开头

2.不能和关键字相同

3.区分大小写

4.由长度限制

5.顾名思义

三.基本数字类型#

存储单位： 1GB = 1024MB

1MB = 1024KB

1KB = 1024Byte

1Byte(字节） = 8bit（位）

🔴byte为计算机中常用的储存单位

bit为计算机中最小的单元

1.整型（占位符为%d）

short（短整型）：2字节，取值范围：-32768~32767

int（整型）常用：4字节，-2147483648~2147483647

long（长整型）：4字节，同上

2.浮点数（%f）和字符型（%c）

float（单精度浮点型）：4字节（能保留小数点后6-7位）

double（双精度浮点数）：8字节（能保留小数点后15-16位）

char（字符型）：1字节，-128~127，这是一个整数类型（存放“单个符号”） eg：char letter = 'A' A在ASCII码表中对应的数字是65 想打印成字符（字母）：用%c。想打印成数字（ASCII码）：用%d

不能被修改的量

1.普通常量：数值常量，字符常量，字符串常量（常量后要加f，eg：1.23f）

2.转义字符（要用\转义） \n(换行）

\t(制表符）

\(两个反斜杠为一个）

'（单引号）

"（双引号）

五.变量#

其值可以变化的量

先定义再使用

定义格式：

数据类型 变量名；

eg： int age；

float heigh；

char sex；

1.有符号变量（决定了变量能不能存负数）：通过signed修饰，缺省signed默认是有符号（可以省略）

2.无符号变量：只有整数类型能够声明为无符号的类型，通过unsigned来修饰（绝对不能省略，如果只想存正数一定要加unsigned）

eg：unsigned int age；

•有符号：能存负数，范围是对称的（正负各一半）。

• 无符号：只能存非负数（0和正数），最大值是有符号的两倍。

用const修饰的量

定义格式：const 数据类型 变量名；（定义时必须赋值）

加上const变量就不能变了，不让变量的值发生改变

六.运算符#

说明特定操作的符号

分类：算术运算符，赋值运算符，关系运算符，逻辑运算符和位运算符等

按修饰的操作数个数分类：单目，双目和三目运算符

1.算术运算符

+，-，*（乘），/（除），%（模），++（自增），--（自减）

%也是除法，但最后结果取值为余数

/整数除法，如果两边都是整数，结果为整数，不保留小数。如果两边有一个是浮点数结果保留小数。eg：5 / 2.0=2.500000

++和--（单目）：

前置：先自增自减后运算

后置：先运算后自增自减

eg： 前置自增：

angelscript
 int a = 5;
int b = ++a; 
// 步骤：a 先加 1 变成 6，然后把 6 赋值给 b
// 结果：a = 6, b = 6

后置自增：

dns
int a = 5;
int b = a++; 
// 步骤：先把 a 原来的值 5 赋值给 b，然后 a 自己再加 1 变成 6
// 结果：a = 6, b = 5

2.关系运算符

,<,>=（大于等于）,<=（小于等于）,==（等于）,!=（不等于） (1为真，0为假）

eg：

cpp
#include <stdio.h>

int main() {
int a = 10;
int b = 20;

// 1. 大于
printf("a > b 的结果是: %d\n", a > b);   // 10 > 20 是假，输出 0

// 2. 小于
printf("a < b 的结果是: %d\n", a < b);   // 10 < 20 是真，输出 1

// 3. 大于等于
printf("a >= 10 的结果是: %d\n", a >= 10); // 10 >= 10 是真，输出 1

// 4. 小于等于
printf("b <= 15 的结果是: %d\n", b <= 15); // 20 <= 15 是假，输出 0

// 5. 等于（注意是双等号 ==）
printf("a == b 的结果是: %d\n", a == b);  // 10 == 20 是假，输出 0

// 6. 不等于
printf("a != b 的结果是: %d\n", a != b);  // 10 != 20 是真，输出 1

return 0;
}

运行结果为：

stylus
a > b 的结果是: 0
a < b 的结果是: 1
a >= 10 的结果是: 1
b <= 15 的结果是: 0
a == b 的结果是: 0
a != b 的结果是: 1

3.逻辑运算符

&&(并且）

逻辑与：左右两边都为真结果为真，左右两边有一个为假，结果为假

||（或者）

逻辑或：左右两边有一个为真，结果为真，左右两边都为假，结果为假。

！（单目）非

逻辑非：修饰的为真，结果为假，修饰的为假，结果为真

eg：

cpp
#include <stdio.h>

int main() {
int age = 20;          // 年龄
int isDrunk = 0;       // 0 表示没喝醉，1 表示喝醉了

// 1. 逻辑与 && （两个条件必须同时满足）
// 只有 age >= 18 并且 isDrunk == 0 同时成立，才能开车
if (age >= 18 && isDrunk == 0) {
    printf("条件1：可以开车\n"); 
} else {
    printf("条件1：不能开车\n");
}

// 2. 逻辑或 || （只要满足一个条件就行）
// 只要 age 满18 或者 isDrunk 为0（没喝醉），就满足其中一个
if (age >= 18 || isDrunk == 0) {
    printf("条件2：满足至少一个条件\n");
}

// 3. 逻辑非 ! （唱反调）
// 如果 !isDrunk 为真，说明 isDrunk 是 0（没喝醉）
if (!isDrunk) {
    printf("条件3：检测到没有喝醉\n");
}

return 0;
}

运行结果：

text
条件1：可以开车
条件2：满足至少一个条件
条件3：检测到没有喝醉

3.位运算符

&：位与：操作的两个位都是1，得到的结果为1，其他结果为0

• 经典用途：清零、取特定位（掩码）。 • 例子：

tap
5 & 3
• 5 的二进制：0101
• 3 的二进制：0011
• 按位与结果：0001 （十进制 1）

|：位或：操作的两个数都是0，得到的结果就是0，其他情况都是1

• 经典用途：把某些位置为 1。

• 例子：

tap
5 | 3
• 5 的二进制：0101
• 3 的二进制：0011
• 按位或结果：0111 （十进制 7）

~（单目）：位非：位的值为1，结果变成0，位的值为0，结果变成1

例子：

tap
5 ^ 3
• 5 的二进制：0101
• 3 的二进制：0011
• 异或结果：0110 （十进制 6）

^：位异或：操作的两个位不同就是1，其他结果为0

• 例子：

haml
~5
• 5 的二进制（假设8位）：00000101
• 取反结果：11111010 （这是补码，十进制是 -6）

<<（整体向左移动，右边补 0）

• 效果：相当于乘以 2^n。

• 例子：

tap
5 << 1
• 5 的二进制：00000101
• 左移 1 位：00001010 （十进制 10，刚好是 5 × 2）
• 左移 2 位：00010100 （十进制 20，刚好是 5 × 4）

（整体向右移动，左边补 0 或符号位）

• 效果：相当于除以 2^n（取整数商）。

• 例子：

tap
10 >> 1
• 10 的二进制：00001010
• 右移 1 位：00000101 （十进制 5，刚好是 10 ÷ 2）

4.赋值运算符

=，+=，-=，*=，/=，%=，&=，^=

eg：int a = 10； a += 5 等价于 a = a+5 结果为15

5.其他运算符

  1. sizeof 运算符（求字节数）

• 作用：计算一个数据类型或变量在内存中占用的字节数。

• 特点：它是个单目运算符，不是函数。返回值类型是 size_t（无符号整数），所以打印时最好用 %zu。

• 例子：

dns
printf("%zu\n", sizeof(int));   // 输出 4 (32位系统)
printf("%zu\n", sizeof(char));  // 输出 1
int a = 10;
printf("%zu\n", sizeof(a));     // 输出 4
  1. ?: 三目运算符（唯一的三元运算符）

• 语法：条件 ? 表达式1 : 表达式2

• 逻辑：如果“条件”为真，整个式子返回“表达式1”的值；否则返回“表达式2”的值。

dns
int a = 10, b = 20;
// 找出两个数中的最大值
int max = (a > b) ? a : b; 
printf("最大值是: %d\n", max); // 输出 20
  1. , 逗号运算符（顺序求值）

逗号在 C 语言里不仅可以分隔变量，还可以当运算符。

• 作用：把多个表达式连接起来，从左到右依次计算，最终整个式子的结果等于最右边那个表达式的值。

dns
int a = 1, b = 2, c;
// 先算 a+1，再算 b+2，最后把 b+2 的结果赋给 c
c = (a + 1, b + 2); 
printf("c = %d\n", c); // 输出 4 (因为 b=2, 2+2=4)

🔴运算符是有优先级的，单目运算符优先级最高，可以直接加括号（）。括号的优先级是最高的。

七.语句#

当程序运行时执行某个动作的语法结构

1.空语句：只有一个分号，什么也不执行

2.表达式语句：在表达式的末尾加分号

3.函数调用语句：由函数名，实际参数加分号组成

4.复合语句：是用{}将一系列语句括起来，相当于一条语句

5.控制语句：循环，选择/分支，跳转

a.分支结构（做选择）：主要有if和switch

if语句有三种：

（1）形态一： 单分支（如果……就……）

1c
if （条件） { 
    // 条件为真时执行
 }

（2）形态二：双分支（如果……否则……）

actionscript
if（条件） { 
      //条件为真时执行
	}  else {
	   //条件为假时执行
	}

（3）形态三：多分支（如果……否则如果……否则……）

eg：
int score = 85; if (score >= 90) { printf("优秀\n"); } else if (score >= 60) { printf("及格\n"); // 会执行这里 } else { printf("不及格\n"); }

switch语句 当判断条件是一个具体的整数值时，用switch更清晰

eg：

cpp
int choice = 2;
switch (choice) {
case 1:
    printf("你选了1\n");
    break;  // 必须加 break，否则会“穿透”执行下面的 case
case 2:
    printf("你选了2\n"); // 执行这里
    break;
default:  // 相当于兜底，不符合条件时才执行的
    printf("无效选择\n");
    break;
}

🔴注：每个case后一定要加break，否则代码会继续往下执行，叫“case穿透”

b.循环结构

（1）for循环 （最常用，适合知道循环次数）

语法 for （表达式1；表达式2；表达式3） {循环体4；} （按照1243形式循环）

eg：
for (int i = 0; i < 5; i++) { printf("%d ", i); // 输出 0 1 2 3 4 }

（2）while循环（适合不知道循环此时，只知道停止条件）

语法：while（逻辑表达式）{循环体； }

eg：

dns
int i = 0;
while (i < 5) {
printf("%d ", i);
i++;
}

（3）do while语句

先执行一次，再判断条件（哪怕条件一开始就是假，循环体也会执行一次）

语法：do {}while(逻辑表达式）；

cpp
int i = 10;
do {
printf("我会被执行一次\n");
i++;
} while (i < 5); // 虽然条件一开始就是假，但循环体已经执行过一次了

c.跳转语句 （中途变道）

用来在循环或分支中强行改变执行方向

（1）break （跳出当前循环或switch语句，结束循环或switch语句执行）立刻终止整个循环，不再继续）

perl
for (int i = 0; i < 10; i++) {
if (i == 5) break;  // 当 i 等于 5 时，直接跳出循环
printf("%d ", i);   // 输出 0 1 2 3 4
}

（2）continue （跳过本次循环，进入下一次） 不终止整个循环，只跳过当前这一循环，直接开始下一次

perl
 for (int i = 0; i < 5; i++) {
if (i == 2) continue; // 跳过 i=2 的情况
printf("%d ", i);     // 输出 0 1 3 4
}

（3）goto （无条件转移，不推荐）

可以跳到代码里任意一个标签位置。因为它会破坏代码结构，让程序像一团乱麻，现代编程中强烈建议不要使用。

d.嵌套（套娃）分支和循环可以互相嵌套，比如在 for 循环里写 if，或者 for 里面再套 for。

dns
for (int i = 1; i <= 9; i++) {
for (int j = 1; j <= i; j++) {
    printf("%d*%d=%d\t", j, i, i*j);
}
printf("\n"); // 每打完一行换行
}

🔴注：还是遵守1243的顺序循环，一次循环中先完成j再完成i

便于理解：

• 顺序：默认从头走到尾。 • 分支：if 和 switch，根据条件走岔路。 • 循环：for（次数明确）、while（条件明确）、do-while（至少一次）。 • 跳转：break（彻底不干了）、continue（这次先跳过，下次继续）。

八.数组#

1.概念： 类型相同，内存连续的数据的组合 eg：int就全是int，float就全是float

2.格式： 类型说明符 数组名[数组大小]

3.分类：一维数组和多维数组

a.数组：

赋值格式：类型说明符 数组名[数组大小] = { 值 } eg：int a[6] = {1,2,3,4,5,6}

数组的初始化：

（1）数组没有赋值的部分，系统会自动默认为0

（2）当我们没有给数组大小的时候，那么数组的元素的个数就是这个数组的大小

（3)定义数组的时候，初始化只能少给不能多给 eg：int a[6] = { } 花括号里面的值不能超过六个，少于六个剩下的值补0

（4）数组最大的下标为数组大小-1 （数组的值都有下标，eg：int a[6]= {1，2，3，4，5，6} 而1的下标为0，2的下标为1，3的下标为2，以此类推 所以数组的下标从0开始，访问数组的元素从0开始）

访问数组的元素：a[0] 对应1 a[1] 对应2 ……

eg：

apache
 int a[6]= {1，2，3，4，5，6}
 printf（"%d\n",a[0])   //结果为1

b.数组在内存中的存在形式

（1）内存：程序在运行的时候，用来临时存储数据的作用 （eg：计算机输入按下数字的时候，数字在内存中，按了=才会把数据给到CPU

计算机的内存被划分为无数个1字节大小的存储单元，我们可以把内存想象成一排连续的小格子（每个格子1个字节）

内存是可以释放的，当程序运行结束之后，程序就自行释放，所以多次取地址打印的结果都是不相同的

（2） 地址：数据在内存中的编号

&：取地址

规则：64位操作系统用16进制表示（方便阅读）

地址只认第一个字节 假如我声明了int a ，当我用&a取地址时，整个int变量的地址，就等于这四个字节中“起始那个字节”的地址，，打印的都是首地址

eg：

九.函数#

封装功能的容器

1.第一种 当返回值类型是空类型

angelscript
void 函数名（形参列表）
{

  //函数体

}
int main（）
{
   函数名（）；
}

eg：

cpp
#include <stdio.h>

void printadd(int a, int b)
{
printf("%d\n", a + b); 
}

int main()
{
printadd(3, 5); 
return 0;
}

🔴空类型特点：

  1. void 关键字：必须写在函数名前面。

  2. 没有返回值：调用这个函数时，不能把它赋值给变量，也不能写在 printf 里当参数。

  3. return 用法：可以省略不写；如果中途想退出，只能写 return;（不能跟具体数值）。

int main() {

🔴特点：

  3. 类型必须匹配：return 后面的数据类型，必须和函数名前面的类型一致。

（1）返回值类型：基本数据类型

** 以下是不同类型的变量在没有显式初始化时的默认值：

整型变量（int、short、long等）：默认值为0。

浮点型变量（float、double等）：默认值为0.0。

字符型变量（char）：默认值为'\0'，即空字符。

指针变量：默认值为NULL，表示指针不指向任何有效的内存地址。

数组、结构体、联合等复合类型的变量：它们的元素或成员将按照相应的规则进行默认初始化，这可能包括对元素递归应用默认规则。**

🔴总结起来，C 语言中变量的默认值取决于其类型和作用域。全局变量和静态变量的默认值为 0，字符型变量的默认值为 \0，指针变量的默认值为 NULL，而局部变量没有默认值，其初始值是未定义的。

e.变量的声明

变量的声明有两种情况：

1、一种是需要建立存储空间的。例如：int a 在声明的时候就已经建立了存储空间。

2、另一种是不需要建立存储空间的，通过使用extern关键字声明变量名而不定义它。 例如：extern int a 其中变量 a 可以在别的文件中定义的。

（除非有 extern 关键字，否则都是变量的定义）

extern int i; //声明，不是定义

int i; //声明，也是定义

eg:

cpp
#include <stdio.h>

// 函数外定义变量 x 和 y
int x;
int y;
int addtwonum()
{
// 函数内声明变量 x 和 y 为外部变量
extern int x;
extern int y;
// 给外部变量（全局变量）x 和 y 赋值
x = 1;
y = 2;
return x+y;
}
int main()
{
int result;
// 调用函数 addtwonum
result = addtwonum();
printf("result 为: %d",result);
return 0;
}
  1. 语法细节与踩
  • 声明里的参数名可以省略：int add(int, int); 也是合法的。
  • 声明末尾的分号绝对不能少，否则会引发诡异的语法错误。
  • 如果函数不接受任何参数，现代C语言规范要求写上 void：int func(void);，而不是留空 int func();。
  1. 实际工程中的运用 在大型项目中，函数声明通常放在 .h（头文件）里，函数定义放在 .c（源文件）里。主程序通过 #include "xxx.h" 引入声明，从而实现模块化编程。 主函数：每个C程序有且只有一个main（）函数，是程序的执行入口 程序从main()开始执行，返回值通常为0表示程序成功执行，非零值表示出现了错误
