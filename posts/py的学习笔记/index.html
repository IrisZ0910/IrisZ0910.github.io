一.python#

是强类型的动态脚本语言

是一种面向对象的解释型高级编程语言

二.出现的常见四种bug：#

1.中文符号（必须英文模式下）

2.缩进错误(四个空格)（print 顶格写)

3.无效语法（一个print必须单独写一行)遇到syntax说明语法有问题

4.命名错误(中英文必须加引号单双都可以，数字不加引号)

三.debug中#

1.代码为蓝色时，代表即将要运行

2.step out(跳到下一个断点)

四.注释.#

单行注释:用#井号，放在代码前后都可，但注释右边不可被执行，起辅助说明作用。

多行注释:用三对引号包含，单双都可以，注释内容也不会被执行

五.快捷键#

1.ctrl+/单行注释，既可添加，也可取消注释

2.ctrl+Z 撤销上一步操作

3.+C复制

4.+V粘贴

5.+F查找

6.+D复制到下一行

六.输出函数print（）#

1.输出多个值或多句话，需要用，隔开（英文模式下）eg：print(“哈哈哈”，“嘻嘻嘻”，“呵呵呵”)效果为用空格隔开

2.sep，使用sep间隔多个值eg:print(“哈哈哈”,”嘻嘻嘻”，”呵呵呵”,sep=“,”)

3.end，使用end用来拼接两个运行的字符

print（“字符串”，end =“后面拼接的值”) 最后输出结果:第一个print中的字符串+后面拼接的值+第二个print中的字符串

七.变量#

1.概念:一个容器，计算机当中的储存空间

2.作用:在计算机内存中保存数据

3.定义变量的格式:变量名 = 值(=是赋值运算符左右两边打上空格是为了代码的规范性，美观性)

（加上引号会打印引号的内容，不加引号就是变量名，打印的是变量的值）

（变量只有被赋值之后才会被创建，使用变量之前要先赋值）值:英文和汉字时都要加引号

🔴一个变量可以反复赋多个值，首次使用变量会在内存中划分空间，并初始化值。再次使用这个变量不再划分空间，修改原空间的值！

（代码是从上往下运行的）

绝对不能以数字作为开头

5.变量的命名规范

a.见名知宜 eg:name = "yaoyao"

b.下划线分割法(python常用)

多个单词组成的名称，使用小写字母，单词与单词之间使用下划线分开

c.大驼峰命名法

多个单词组成的名称，每个单词的首字母大写，其余字母小写

d.小驼峰命名法

多个单词组成的名称，第一个单词都小写，后面的单词首字母都大写

十一.算数运算符#

1.除/：商一定为浮点数

2.整除//：商只取整数，当除数有浮点数时，商也为浮点数

3.%：商只取余数

4.幂：mn：m的n次方

优先级：幂（最高优先级）》乘，除，取余，取整数>加减

十二.赋值运算符#

运算符 含义 示例 等价于

= 基本赋值 a = 10 把 10 赋给 a

+= 加后赋值 a += 3 a = a + 3

-= 减后赋值 a -= 3 a = a - 3

*= 乘后赋值 a *= 3 a = a * 3

/= 除后赋值 a /= 3 a = a / 3

//= 整除后赋值 a //= 3 a = a // 3

%= 取模后赋值 a %= 3 a = a % 3

**= 幂后赋值 a **= 3 a = a ** 3

&= 按位与后赋值 a &= 3 a = a & 3

|= 按位或后赋值 a |= 3 a = a | 3

^= 按位异或后赋值 a ^= 3 a = a ^ 3

<<= 左移后赋值 a <<= 1 a = a << 1

十三.输入函数#

Python 的输入函数主要是 input()，读取键盘输入。

  1. 基本用法

    dns
    name = input("请输入姓名：")
print("你好，", name)

运行：

text
   请输入姓名：小明
   你好， 小明

🔴关键点：input() 的返回值永远是字符串 str

  1. 输入数字要转换

    dns
    age = int(input("请输入年龄："))
print(age + 1)

输入：

text
 请输入年龄：18
 19

浮点数：

dns
 score = float(input("请输入成绩："))
 print(score * 2)

输入：

text
请输入成绩：85.5
171.0
  1. 一次输入多个值

用 split() 按空格切分：

dns
a, b = input("请输入两个数，用空格分隔：").split()
a = int(a)
b = int(b)
print(a + b)

输入：

text
请输入两个数，用空格分隔：3 5
8

更简洁的写法：

dns
a, b = map(int, input("请输入两个数：").split())
print(a + b)

简单理解：

  1. input() 返回字符串，数字要 int() / float() 转换。

  2. input("提示语") 的提示语会显示在输入前。

  3. 多个值用 split() 切分，配合 map() 转换类型。

  4. 输入不是数字时 int() 会抛 ValueError，可用 try/except 处理。

split（）：作用时按指定分隔符，把一个字符串切成多个字串，返回一个列表

语法：字符串.split（分隔符） 如果不写分隔符，默认按任意空白字符切分（空格，换行，Tab等）

map（）：把一个函数依次作用到可迭代对象的每个元素上，返回一个新的迭代器

语法：eg：map（int，nums） 相当于把nums中的元素都转换为整数

map对象是一次性的，print取完就空了

十五.if判断，比较运算符，逻辑运算符，三目运算#

1.if后要用：冒号 下面要执行的命令必须缩进（最好自动缩进）

2.比较运算符

== 等于 3 == 3 True

!= 不等于 3 != 4 True

大于 5 > 3 True

< 小于 5 < 3 False

= 大于等于 5 >= 5 True

<= 小于等于 3 <= 2 False

注：结果都为布尔值，true，false

3.逻辑运算符

and 与（都真才真） 相当于&&

or 或（有一个真就真） 相当于||

not 非（取反） 相当于!

优先级：not > and > or

4.三目运算符

（条件表达式）是一行写 if-else 的简写，用来根据条件二选一。

语法：值1 if 条件 else 值2

含义：条件为 True，取值1；条件为 False，取值2。

eg：

freedesktop
age = 20
result = "成年" if age >= 18 else "未成年"
print(result)      # 成年

十六.嵌套#

嵌套（nesting） 就是在一个结构里面再放一个同类的结构。

Python 里常见嵌套：

if 里面套 if → 条件嵌套

for 里面套 for → 循环嵌套

for 里面套 if → 循环里套条件

函数里定义函数 → 函数嵌套

关键：靠缩进表示层级，缩进越多，层级越深。

apache
if 条件1:
    if 条件2:          # 第 2 层
        print("都成立")  # 第 3 层

十七.循环#

  1. for 循环

遍历一个序列（列表、字符串、range 等），逐个取出元素。

语法： for 变量 in 可迭代对象: 循环体

理解：eg：for i in range（start，stop）

eg：

dns
for i in range(5):
print(i)

输出：

text
0
1
2
3
4
  1. while 循环

条件为真就一直循环。

语法： while 条件: 循环体

eg：

apache
i = 0
while i < 5:   #当i = 5时停止循环
print(i)
i += 1        # 千万别忘了，否则死循环

输出：

text
0
1
2
3
4

场景 用哪个 知道循环次数 / 遍历序列 for 不知道次数，靠条件结束 while

4、循环控制：break 和 continue

（1）. break：立刻跳出整个循环

（2）. continue：跳过本次，进入下一次

  1. for-else 和 while-else（Python 特色）

循环正常结束（没被 break 打断）时，执行 else：

eg：

stylus
for i in range(5):
if i == 10:
    break
print(i)
else:
print("循环正常结束")

输出：

text
0
1
2
3
4

循环正常结束

如果被 break 打断，else 不执行：

5.循环嵌套

一个循环里面再放一个循环，外层走一次，内层走一整圈。

  1. 基本结构

    dns
    for i in range(3):        # 外层
 for j in range(2):    # 内层
   print(i, j)

输出：

basic
0 0
0 1
1 0
1 1
2 0
2 1

规律： 外层 i=0 → 内层 j 走完 0,1 外层 i=1 → 内层 j 走完 0,1 外层 i=2 → 内层 j 走完 0,1
